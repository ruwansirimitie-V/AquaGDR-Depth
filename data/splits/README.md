# Dataset split files

Place `train.txt`, `val.txt`, and `test.txt` here. Each line contains two
paths relative to `data/underwater_erp`, separated by whitespace:

```text
rgb/panorama_0001.jpg depth/panorama_0001.png
```

The dataset and split lists are not included in this repository. Use only data
you are authorized to access and follow the original dataset terms.
